# PDF-to-Word-Agent
AI-powered document processing application for PDF to Word conversion, OCR, summarization, and Word document generation using Python and Streamlit.
## Features
* Upload PDF files
* Extract text from PDF documents
* Convert PDF content into editable DOCX format
* Download converted Word documents
* Simple and user-friendly interface
* Built with Python and Streamlit

## Technology Stack
* Python
* Streamlit
* PyMuPDF (fitz)
* python-docx

## Project Structure

PDF-Intelligence-Agent/

├── app.py

├── converter.py

├── requirements.txt

└── README.md

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/PDF-Intelligence-Agent.git
cd PDF-Intelligence-Agent
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## Usage

1. Open the Streamlit application.
2. Upload a PDF file.
3. Click the Convert button.
4. Download the generated Word document.
